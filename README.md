# 🎁 موقع الهدية الرقمية للأخت / الأخ (باللغة العربية بالكامل)

موقع هدية رقمية تفاعلي، مصمم خصيصاً كهدية أخوية دافئة ومبهجة بمناسبة عيد الميلاد والذكريات المشتركة، مع دعم كامل للغة العربية والاتجاه (RTL).

---

## ✨ المميزات المضافة والمُحسنة:

1. **الظرف التفاعلي المتقن (تم حل مشكلة الشكل تماماً)**:
   - تم بناء الظرف هندسياً بدقة متناهية وبتقنية `clip-path` ليكون متناسقاً تماماً على جميع الشاشات والموبايل وبدون أي فراغات أو أخطاء.
   - عند الضغط على الختم الذهبي، ينفتح الغطاء العلوي بسلاسة ثلاثية الأبعاد، وترتفع الرسالة للأعلى لتعرض نص الترحيب وزر فتح الخزانة.
2. **بوابة كلمة السر السرية**:
   - قفل سري يحمي الذكريات بكود سري (الافتراضي: `1234`).
   - زر إظهار/إخفاء كلمة السر، وزر التلميح، ورسائل تنبيه عربية طريفة عند الخطأ، ونغمة احتفالية عند النجاح.
3. **محتوى أخوي واقعي ودافئ (دون الحاجة لانتظار الصور)**:
   - ذكريات أخوية أصيلة (الطفولة، خناقات الريموت والأكل، الأسرار المشتركة، الفخر بالنجاح، والاحتفال بعيد الميلاد).
   - صور توضيحية مؤقتة جاهزة وأنيقة لا تظهر فارغة إطلاقاً أثناء انتظار الصور الحقيقية.
4. **لوحة الذكريات الرئيسية**:
   - **العداد الحي**: يحسب بالثانية والأيام والساعات والسنين مسيرة الأخوة مع زر فرقعة الزينة.
   - **محطات رحلتنا**: شريط زمني تفاعلي لذكريات ومواقف مشتركة.
   - **مشغل أسطوانات الفينيل**: أسطوانة تدور مع تشغيل الموسيقى، مع نغمة هادئة تعمل تلقائياً في حال لم يتم وضع ملف صوتي خارجي.
   - **لقطات وذكريات خاصة**: كروت بولارويد بصور وخواطر خاصة بديلة لشات الرسائل، مع زر التفاعل وزيادة المحبة وإمكانية تكبير الصور.
   - **الهدية المخفية (لسه في حاجة مخبيهالك 🎁)**: صندوق هدايا تفاعلي ينفجر زينة وكونفيتي ويكشف عن **3 كوبونات أخوية ذهبية** (وجبة على حسابي، الفوز بأي خناقة، خدمة بدون تذمر) ورسالة من القلب.
   - **ألبوم الصور الكامل**: مع لايت بوكس لتكبير الصور والتنقل بينها.

## ⚡ كيف تضع صورك الحقيقية وتعدل النصوص؟

كل ما عليك هو فتح ملف **`config.js`** في أي محرر نصوص:

1. **لتعديل الأسماء أو كلمة السر:**
   ```javascript
   recipientName: "MK",              // اسم أختك أو دلعها
   senderName: "أخوكي",              // صفتك أو اسمك
   secretPassword: "1234",          // كود الدخول
   ```

2. **لتعديل تاريخ البداية (للعداد الحي):**
   ```javascript
   relationshipStartDate: "2006-08-15", // تاريخ الميلاد أو البداية بتنسيق YYYY-MM-DD
   ```

3. **لوضع صورك الخاصة عندما تصبح جاهزة:**
   - ضع صورك داخل المجلد `assets/images/` بالأسماء:
     - `memory1.jpg`
     - `memory2.jpg`
     - `memory3.jpg`
   - أو أضف أي صور جديدة وضع مساراتها داخل `config.js` بسهولة.

4. **لوضع أغنيتكم الخاصة:**
   - ضع ملف الـ MP3 داخل `assets/audio/` وسمّه `our-song.mp3`.
